# Are You Critting Me!?

React + Vite starter website for **Are You Critting Me!? — A D&D Catastrophe**.

## Run locally

1. Install a current Node.js version supported by Vite.
2. Open this folder in Terminal.
3. Run:

```bash
npm install
npm run dev
```

Open the local URL shown in Terminal.

## Build for production

```bash
npm run build
```

The finished production files will be created in the `dist` folder.
