# Are You Critting Me!?

**A D&D catastrophe set in the world of Calderon.**

Welcome to the official website project for **Are You Critting Me!?**—an actual-play podcast where four actors, storytellers, and comedians attempt to save the world while making deeply questionable decisions.

The towers are dimming. Chaos is spreading. The dice are rude.

## About the Show

**Are You Critting Me!? — Calderon: Dawn of Chaos**

Welcome to the Second Age of Calderon.

Years after the thousand-year war known as the Recreance—a devastating conflict between the Gods and the Demon Lords—the Rift remains.

Now, four unexpected strangers have become bound together. Their mission: discover why the light of the four towers is fading and why whispers of chaos are spreading across the land.

Their qualifications are unclear.

Their confidence is excessive.

Their survival is not guaranteed.

## Run the Project Locally

Clone the repository:

```bash
git clone YOUR-REPOSITORY-URL
```

Move into the project folder:

```bash
cd are-you-critting-me
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address shown in the terminal, usually:

```text
http://localhost:5173
```

## Available Commands

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```


